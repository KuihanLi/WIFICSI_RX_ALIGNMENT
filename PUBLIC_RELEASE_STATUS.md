# Public release status

As of 2026-09-29, the first frozen publication-facing code snapshot is available at `public_code/b2_mean_frozen/`.

This release exposes the B2_MEAN model, sanitized frozen configuration, training semantics, provenance notes, and a smoke test. It does not include private dataset-routing metadata or the unreleased de-identified CSI dataset.

The complete end-to-end reproducibility package remains under staged release preparation.
